# 원본 기준 구현과 공개 계수

Grackle 3.4.1의 선택한 소스·header·license를 byte-preserving 복사했다. LICENSE와원저자고지를보존하며전체standalone빌드를뜻하지않는다. 현재provider테스트의기준으로만사용하고전체dependency가필요하면동일commit에서가져온다. PHYSICS API/데이터정확도는본문계약에따른다.
