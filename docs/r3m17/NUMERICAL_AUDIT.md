## Ranked actionable findings

1. **Implementation-verified: ray-distance cancellation.** `scripts/r3m16_target_only_hdt.py:78–88` computes distance via overlap subtraction, saturating to zero for exact normalized ray distances 1e-8,1e-9,1e-11,1e-13. `NUMERIC_FLOOR=1e-13` therefore does not represent actual algorithmic resolution. Existing R3M13 direct phase-aligned difference returns each exact distance. Fix in a new utility: weighted, stable aligned residual, separately reported raw fidelity/norm, no silent invalid clipping. Actual R3M16 distances around 1e-4 to 1e-2 are not shown wrong by this defect. Reproduction `numerical_audit.py`, output `numerical_audit.json`.

2. **Implementation-verified: analysis accepts wrong authority and labels it complete.** `scripts/r3m16_analyze.py:63–76,87–117` hardcodes h/dt, never checks result completion/config/source family/initial binding or diagnostic provenance. A copied B1 result with status=checkpoint, h=.125, E=225, requested dt=.5, source=MISMATCH is accepted as COMPLETE_2_NEW_COLLISIONS and labeled h=.20. Historical actual inputs are not alleged wrong. New production analyzer must validate explicit full config family, completed status, source+backend, nstep/actual dt exact horizon, authoritative initial state equality via witnesses, current versus legacy channels, and file identities before computing. Reproduction in same script.

3. **Derived scientific gate defect: a two-level probability difference is not a residual time-error bound.** `decide()` can declare representation blocker from a small pair difference with `target_only_clean=False`; conversely clean static target-only apparent order is allowed to declare full-collision representation change despite unresolved collision time sensitivity. Counterexample: P(dt)=P0+C(dt-d0)(dt-d1) gives identical coarse values and arbitrary offset from P(0); even clean target-only propagation says nothing about moving projectile temporal quadrature. Current TIME_REFINEMENT_STILL_OPEN is conservative and remains valid. Future gates require full-collision actual-step contraction, signed differences and justified residual estimate tagged empirical, with target-only tests diagnostic only. B2 alone can provide first three-level temporal information, not certify all temporal orders or all-channel global error.

4. **Derived/configuration-verified: C is not a constant transverse mesh-phase h-ladder.** A/B projectile closest x,y offsets are (.5h,.5h); C is (.1h,.5h), owing b=2 and x_lo=-30 with h=.3125. Thus minimum transverse radius is .7071068h for A/B and .5099020h for C. Target offsets remain (.5h,.5h,.5h). Three-point spatial Richardson comparisons involving C confound mesh phase. Finite-difference observable h effects remain observations, but a smooth h asymptotic model is an additional unverified assumption. Record fractional nuclear position and nearest sampled Coulomb distances, and validate grid translation sensitivity before production. A/B themselves match transverse phase.

5. **Derived/configuration-verified: moving-cusp time sampling is independent of static Strang test.** At B0 the projectile moves .50167224 h per step (1.99333 steps/cell). This is .25097602 h for B1 and about .12549 h for B2. Midpoint sampling is correctly implemented, but frozen-target diagnostics omit the explicit time-dependent potential terms. A target-only BCH commutator explanation does not isolate their contribution. Also kinetic phase dt*max(k²/2) is large in the full FFT operator norm; it is a diagnostic, not a universal CFL instability condition for unitary split propagators. Add exact cheap preflight metadata plus future moving-center benchmarks.

6. **Implementation-verified recovery limitation: checkpoint pair update is not transactional.** `cr_repro/tdl.py:_save_checkpoint` replaces state.npy then state.json; ControlledTDLRunner writes the seal afterward. Injected interruption after replacing the next array loses previous sealed array while old metadata/seal remain, causing `checkpoint hash mismatch` on resume. Detection fails closed correctly, but prior verified checkpoint cannot be recovered. Existing test interrupts in a later step and does not exercise this window. For production, save immutable complete generations and atomically switch pointer, or preserve one independently sealed previous generation at coordinator layer. Do not silently patch frozen source or rewrite old seals. Repro `checkpoint_atomicity.py` / `.json`.
