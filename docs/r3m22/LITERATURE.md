# R3M22 source-bound numerical analysis notes

Scientific interpreter at this run: Python 3.12.3, NumPy 2.5.3, SciPy 1.18.1, CuPy 14.2.0. The local `scripts/r3m20_matrix_free.py` and `scripts/r3m21_cf4_reference.py` determine actual implementation behavior; external sources do not certify it.

- Jawecki, Auzinger & Koch, [Computable upper error bounds for Krylov approximations to matrix exponentials and associated φ-functions](https://link.springer.com/article/10.1007/s10543-019-00771-6), *BIT Numerical Mathematics* 60 (2020), Theorem 1, DOI 10.1007/s10543-019-00771-6. SciSpace discovery and primary article inspection on 2026-09-23. For an exact-Arnoldi approximation to a nonexpansive semigroup, `||L_m(t)v||₂ ≤ τ_{m+1,m} γ_m t^m/m!`, with `γ_m=∏_{j=1}^{m-1}(T_m)_{j+1,j}`. This is an analytic upper bound in the paper's assumptions, unlike the current empirical scalar phi1 indicator. The finite-precision FFT/CuPy implementation needs independent numerical repeats; its computed number is not a global floating-point certificate.
- Al-Mohy & Higham, [Computing the Action of the Matrix Exponential, with an Application to Exponential Integrators](https://eprints.maths.manchester.ac.uk/1591/), *SIAM Journal on Scientific Computing* 33 (2011). Primary author-repository record inspected 2026-09-23. An alternative action algorithm uses scaling and truncated Taylor with backward-error tolerance. This is a method alternative, not a tested production replacement in R3M22.
- Hochbruck & Lubich, [On Krylov Subspace Approximations to the Matrix Exponential Operator](https://doi.org/10.1137/S0036142995280572), *SIAM Journal on Numerical Analysis* 34 (1997). Located through SciSpace on 2026-09-23. General Krylov exponential action analysis; no production numerical claim imported.

For the frozen discrete generator `A=-iH-W`, with discrete Hermitian `H` and `W≥0`, `A+A†=-2W≤0`. A real linear combination of the two time-dependent Hermitian H values remains Hermitian even though CF4 has a negative coefficient; each CF4 exponential uses CAP coefficient `a+b=1/2>0`. Thus the exact stage semigroup is nonexpansive. The Wolfram lazy proxy returned exact identities `{a+b,c1+c2,a c1+b c2,b c1+a c2}={1/2,1,1/12,5/12}` and a 2×2 Hermitian-H/diagonal-W symbolic example gave `A+A†+2W=0`. This checks these identities, not the full CF4 order theorem or the numerical implementation.

For the new action candidate, apply the published bound to the *scaled* stage operator `B=Δt A_stage/substeps` at `t=1`. If the input Euclidean norm is β, the computed exact-arithmetic bound is `β h_{m+1,m} ∏_{j=1}^{m-1}h_{j+1,j}/m!`. Multiplying by `sqrt(dV)` converts it to the raw physical-state L2 used by the experiment. Sum local bounds across contractive exact stages for a conservative global inner-action budget; keep FFT/orthogonalization roundoff as an unbounded empirical remainder checked by independent repeats.
