## R5 정확한 pair와 exposure 적분

고정 proper-time slab에서 `N'=-kNA`, `A'=-kNA`, `N(0)=N0`, `A(0)=A0`, `k≥0`.

`d=|N0-A0|`, `m=min(N0,A0)`, `z=k d Δt`, `φ(z)=(1-e^-z)/d` for d>0, `φ=kΔt` for d=0.

`m1=m exp(-z)/(1+m φ)`, `L=m-m1`, `N1=N0-L`, `A1=A0-L` (or store common minority to preserve N-A exactly). For z→0 evaluate `φ=kΔt exprel(-z)` and `L=m[(1-e^-z)+mφ]/(1+mφ)` using `expm1`, avoiding cancellation. At exact equality the solution is `m1=m/(1+kmΔt)`.

The exact *absorber exposure* in `(per H) × seconds` is

`I_A = max(A0-N0,0)Δt + log1p(m φ)/k`.

The corresponding photon exposure is `I_N=max(N0-A0,0)Δt+log1p(m φ)/k`.

Proof: for N0>=A0, N=A+d and `d(log N)/dt=-kA`, hence `∫A dt = k^-1 log[N0/N1] = k^-1 log(1+mφ)`. For A0>N0, `A=N+d` and the integral gains `dΔt`. Boundary `k=0`: `I_A=A0Δt`, L=0. Limit d=0: `I_A=log1p(kmΔt)/k`. Both nonnegative.

Wolfram Language symbolic four checks of minority ODE, antiderivative derivative, equal-population limit and initial condition yielded `{0,0,0,0}`; an intermediate `Power::infy` warning was emitted during removable limiting forms, final values zero.

Define the *exposure-weighted photo coefficient* `Γ_exp=L/I_A` (s^-1), so that the **exact integrated event** is `L=Γ_exp I_A`. Similarly per-absorber heat input `H_exp=L(E-χ) EV_ERG/I_A` erg/(absorber·s). For a real measured exposure, this remains a physically interpretable absorber-weighted time-average of the instantaneous coefficient `k N(t)`.

By contrast, the native endpoint backward Euler input that forces the same event is `Γ_BE=L/(Δt A1)` and `H_BE=L(E-χ)EV_ERG/(Δt A1)` where `A1>0`. For strictly photo-depleting A, `I_A/(Δt A1)≥1`, so `Γ_BE/Γ_exp≥1`. As `A1→0` with L>0 it is undefined or ill-conditioned. If `A1=0` and L>0, return `HOLD_ENDPOINT_RATE_UNREPRESENTABLE`, **not** an arbitrary ε floor or source clipping. If L=0 and A1=0, Γ may be represented by 0, while no information about the unobservable instantaneous rate is inferred.

For recombination/ionization mixtures A(t) need not be monotone: the inequality `Γ_BE≥Γ_exp` is **not** asserted; only algebraic exposure/event identities survive given actual exposure. For multi-photon palindromic operator splitting, summing each pair-map pseudo-time exposure over all photon rays does **not** produce a physical common-epoch `∫A(t)dt`. Use an independently integrated physical trajectory or a physically time-aligned quadrature for that input, and record the approximation order. The packaged tests explicitly distinguish these levels.
