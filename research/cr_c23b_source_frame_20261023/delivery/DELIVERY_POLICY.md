# Finite delivery chain

The science commit is immutable. Its complete main ZIP has two actual R3 provider readbacks. This document commit records scientific authority, final scope and those receipts. Its exact commit SHA is bound after publication by an external receipt; a Git commit cannot embed its own SHA.

The final-documents ZIP contains these exact document bytes and their actual publication receipt. The standalone authority and final-documents ZIP are backed up and read back. A terminal transport receipt records their actual provider identities without recursively demanding its own ID inside itself. No successful provider proves a different provider's preservation. Drive remains per-artifact OPEN/UNKNOWN/NOT_ATTEMPTED as recorded.
