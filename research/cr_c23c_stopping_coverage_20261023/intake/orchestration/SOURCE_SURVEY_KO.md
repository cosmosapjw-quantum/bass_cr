# 소스 조사 범위

계획은 저장된 원 저자 계약과 선택한 최신 소스의 인수인계 자료를 근거로 조립했다. 브랜치 목록·PR 메타데이터 조사와 전체 브랜치 내용 읽기는 구별한다. `DAG.json`의 각 노드는 원본 계약 JSON 포인터와 파일 SHA256을 보존한다. 과학적 승인과 실제 수치 실행 결과는 원 저장소의 증거 범위에서만 해석한다.

Library 목록은 133개를 열거했고 2026-10-22 UTC 이후 수정된 작업 관련 이름 38개만 메타데이터로 선별했다. 이름 기반 선택은 내용 검토의 증명이 아니다. Drive 기존 dossier 폴더는 1000개 상한이며 별도 검색은 4개 결과로 제한되었다. Dropbox immediate dossier 폴더는 6페이지, 3366개에서 종료됐으나 이는 전체 Dropbox나 모든 과거 자료의 완전성을 뜻하지 않는다. 대화 검색은 3회이고 마지막 7개 스레드 응답 일부가 잘려 전체 대화 검토를 주장하지 않는다. 개인 대화 본문 및 무관한 대용량 공급자 목록은 공개 소스 묶음에서 제외했다.

원 저자별 구체적인 저장소 조사 범위와 현재 핀은 해당 survey 및 `SOURCE_COVERAGE.json`에 있다. 외부 선행 항목은 `external_dependencies`에 보존하며 누락 입력이 자동으로 충족됐다고 판정하지 않는다. 계획 노드는 실행 전 상태와 예산·보류 조건을 그대로 유지한다.

S0 ZIP은 실제 초기 수집 시점의 부분 스냅샷이다. 이후 조립본이나 검토 상태로 소급 해석하지 않는다. 공급자 ACK와 로컬 SHA256은 서로 다른 검증 범위다. ACK만 있는 경우 원격 전체 바이트 재다운로드 검증으로 해석하지 않는다.
