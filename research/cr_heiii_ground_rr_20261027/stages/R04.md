# R4 — 경쟁 표현과 판별 예제

## 비교한 두 연산자와 선택

A는 K1=KHeI,stored+Dnew다. 이전의 실제 저장 행렬·열을 명시적인 수치
baseline으로 쓰므로 과거 계산을 재생하지 않고 새 항의 영향만 계산한다.
B는 KH1,stored+DHeI+Dnew의 실수합이다. B는 HeI의 과거 대각 덧셈 반올림을
되돌린 별도 수치 문제이므로 A와 같은 이름으로 취급하지 않는다.
이번 목표에는 A를 선택하고 B의 과거 loss 진단을 상속한다.

새 event 확률을 별도 사슬에서 계산해 기존 확률에 합하는 표현과,
모든 first-event reward가 같은 K1을 쓰는 표현을 비교했다. 경쟁 채널은
같은 tagged trajectory를 종료시키므로 후자가 확률 partition을 보존한다.
새 구성은 18 physical, 5 conditional-time, 4 stable-response, 1 diagnostic
RHS다. 과거 RHS를 다시 푸는 것이 아니라 바뀐 K1의 새 문제를 푼다.

## 손으로 계산한 첫 2-state 예제

K0=[[3,−1],[−2,4]], λ=(1/10,1/5), D=diag(λ)로 둔다.
K0는 두 행의 killing rate가 모두 2인 transient operator다.
기존 terminal RHS를 entry=(1/2,1/2), CE=(1/2,1/2),
H1=(3/5,7/10), HeI=(2/5,3/10)로 나누면 합이 K0·1과 같다.

K1의 determinant는 551/50이며 다음을 직접 얻는다.

    p_new = (31/551, 41/551)
    w = K0⁻¹ λ = (3/50, 2/25), eta=2/25
    w/(1+eta) = (1/18, 2/27)
    t0 = (1/2,1/2)
    t1 = (260/551,255/551)
    delta_t = −p_new/2 = (−31/1102,−41/1102)

따라서 lower ≤ p_new ≤ upper가 두 상태에서 성립한다. 새 H1 확률은
(161/551,337/1102), 새 HeI 확률은 (99/551,173/1102)이며,
entry=CE=(130/551,255/1102)와 p_new를 합하면 두 상태 모두 1이다.
이 유리수 예제는 채널 간 competition과 stable response를 함께 판별한다.
R7에서 독립 CAS로 같은 식을 검산한다. 이는 원자율 측정값이 아닌
유한 연산자 구조를 검사하는 명시적 예제다.

## 에너지·외부 사상의 표현 선택

새 count reward p, kinetic reward r에는 photon=r+I p와 internal=−I p를
같은 해에서 구성한다. source-weighted 적분 count와 energy를 그대로
반환하고, 아직 공급되지 않은 source rate는 null로 둔다.
native25 state에는 abundance/fast count/fast energy만 사상하고 retained
photon은 별도 output port에 둔다. signed external w_ext의 의미는 보존한다.

watchdog: 새 추상 형식 대신 실제 저장 필드·18열 인덱스·한 사건 column에
연결했다. 기존 rate-only API와 pulse-integrated 출력의 차원 충돌은 별도
integrated adapter로 최소 수정한다. 새로운 전체 transport framework는
이 단위의 의존성이 아니다.
