# 이번 요청의 정책 적용

사용자가 2026-10-28에 다음 이론 연구 루프와 그 구현 코딩 루프를 요청하고 physmath1.0 본문을 직접 제공했다. 이번 선택 범위는 새 단위 R1–R10/C1–C10이다. Plugin1.3의 bare-invocation 단일 단계 기본값과 프로젝트 첨부의 옛 한 단계 실행/매 단계 반복 audit 규칙을 이번 명시적 전체 요청에 적용해 축소하지 않는다. 사용자 고정 물리·identity·예산·null·권한은 유지한다.

공통정책의 실제 유도·변경 의존성 검증·NG1–NG7·과잉 형식화 교정과 plugin1.3의 bounded checkpoint, blindretry/진단수정 구분, 한 번의 실질 독립 검토를 따른다. 새 강한 no-go를 주장하지 않는다. 실제 source-parent pairing 미결은 입력 필드와 affine family로 표시한다. R6/C9에서 물리수학/식–코드 검토를 수행하고 C8에서 필요한 새 그림을 생성·실제 읽는다. 옛 preset의 모든 node마다 같은 그림·감사를 반복하는 방식은 현재 목적과 근거 재사용 규칙에 맞게 통합한다.

Root는 과학판정·합류·게시를 맡는다. source_qualification은 실제 owner/중앙 원문, theory_review는 source모형·문헌·유도, implementation은 실제consumer/코드경로를 분담했다. 동일 canonical 파일을 동시에 편집하지 않는다. 파생물 생성 전 기존 완료 S/D/M·source와closeoutbytes·실제백업영수증을 확인했다. old source/operator/reference는 재실행하지 않는다.
