# CR-PHYS02E: 저장 격자의 의미 보존과 NCP 재시도 준비

이 단위는 실제 PHYS02D NCP 실패를 이어서, 저장 에너지 격자를 G 생성 전에 채택하는 명시적 생성자와 무물리 입력 preflight를 제공한다. 실제 pulse 계산은 이 단위의 준비 과정에서 실행하지 않았다.

- 연구 결과: `REPORT_KO.md`, `research/theory_contribution/DERIVATION_KO.md`
- 현재 판정: `state/RESEARCH_STATE.json`, `review/INDEPENDENT_DECISION.json`, `state/NEXT_DAG.json`
- NCP 시작: `START_NCP_CODEX_KO.md`, 상세 실행: `ncp/README_KO.md`
- 정확 계약: `state/CONTRACT_IDENTITY.json`
- 필수409 dependency: `inputs/DEPENDENCY_PAYLOAD_MANIFEST.json`

완전한 ZIP에는 현재 단위,409 의존 파일, 원본 실제 실패 ZIP, 두 Astra harness가 들어간다. 추가 사용자 첨부 없이 새 isolated repository-layout overlay에서 재개한다. ZIP SHA·백업ID·실제 science commit은 standalone NCP start 및 별도 publication receipt에 고정된다.

원래 연구의 라이선스를 `LICENSE`로 보존한다. 부모 B/C/D와 원자율, source, pulse 엔진, FP64 및 허용오차는 고정 계약의 범위 안에서 유지된다.
