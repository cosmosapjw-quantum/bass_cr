# PHYS02G 읽기 전용 intake 후보 계약 채택

기존 고정 계약은 구현에 충분하다. 이 기록은 후보 계약 해석이며 최종 독립 심사가 아니다. 계약 SHA256 eebca369dbb01b6ad678e110866f919bdd07c7692850330df55f3deab99df0ba 및 기존 준비 심사 SHA256 ba4d6e012a2522cce97c9c9acf9f9976c380d0cba0f4a60aaa306998a8a0b1e2가 CURRENT_NEXT_ACTION의 pin과 일치함을 확인했다.

F는 HOLD_OPERATOR_BINDING_UNRESOLVED, G 실제 frontier는 BLOCKED_BY_F_OPERATOR_BINDING_HOLD다. F의 기존 G 생성 예약/완료는 1/1, execute/collect/wrapper exit은 1/0/1이다. 다음 G·resolvent·solve·pulse·expm·retry·frontier 호출은 모두 0이다. 과거 G 1회/90초 allowance는 미소모이면서 비활성이다.

진단은 이후 한 번의 180초 창에서 수행한다. 양쪽 원본 CSC 값과 provenance 및 정확 raw identity가 모두 확인되는 경우에만 그 창 안에서 최대 1회/90초, block 262144 이하의 저장 배열 비교를 허용한다. 한쪽 값이 없으면 MISSING_PERSISTED_OPERATOR_VALUES와 실제 조회 범위를 남긴다. unbound cache는 CANDIDATE_ONLY다. 값이 있지만 provenance·형식·비교 구현이 부족하면 해당 blocker를 구분한다.

NumPy·SciPy·threadpoolctl·프로젝트 source import/실행은 금지한다. stdlib 파일·JSON·hash·제한된 /proc 조회만 사용하며, 기존 공유 라이브러리 hash는 파일 읽기로 구한다. import 없이 현재 BLAS dispatch를 확인할 수 없다면 NOT_OBSERVED_WITHOUT_IMPORT로 기록한다. 과거 SkylakeX/Haswell 차이는 원인을 입증하지 않는다.

이미 읽은 R3 receipt가 식별한 F root는 /tmp/CR-PHYS02F-EXECUTION-20261011.euer7hqa이며 하위 run/source/return만 관련 조회 후보다. E의 원래 run/cache, interpreter 및 절대 library path는 이후 진단 창에서 지정된 saved runtime/completion/log record의 실제 경로 필드로 추출한다. 호스트 전체나 관련 없는 metadata는 검색하지 않는다. 이번 후보 작성에서는 현재 호스트·cache·runtime을 조회하지 않았다.

read-file SHA256, 입력 identity 및 12개 체크리스트는 CANDIDATE_CONTRACT_ADOPTION.json에 고정했다. canonical 템플릿의 빈 항목은 과학적 근거가 아니다. 요청 역할은 Astra 후보 계약 해석이며 실제 backend의 독립 인증은 없다. 본 작성자는 후보/수용 기준 해석에 참여했으므로 최종 독립 reviewer를 맡을 수 없다.

최초 artifact writer는 python 명령 부재로 실행 전에 exit 127을 반환했다. 이 준비 오류를 JSON에 보존하고 python3의 stdlib-only writer로 두 문서를 작성했다. 진단 창 및 물리 실행은 소비하지 않았다.

기존 G-R01, 상속 gate, 원본 실패와 source/archive bytes를 보존한다. 해시 차이로 오차 크기·원인·roundoff-only·물리적 동등성/비동등성을 결론내리지 않는다.
