# Claims, assumptions and input gates

## Actual input and what is computed

The actual input is the saved PHYS02 source distribution and its source-code law Qe=tA on[0,10^10] proper seconds. It is an executed leading-local prescribed-gas model, not an observed cosmological history. The native proton source is normalized on10keV–1PeV; selected collisions use1–4MeV and electron births0.1–900eV. Neither selected interval is renormalized to the full external source power.

The source columns use common selected-energy normalization U*=1.1242596728743301e-13eV m^-3. Active coordinates b_i are energy coordinates; A_Ni=U*b_i/(T_end² E_i), A_Ei=U*b_i/T_end². Cutoff count/energy are separate source components. low_cross diagnostics are duplicate bookkeeping, not additional injections. fullBED and legacy encode the same source and are not independent donor events.

Derived scope: once-only measure conversion, finite polynomial time integration, number/energy ownership, compatible RR return ports, and the baryon-denominator correction. Numerical scope after C6–C9: actual saved discrete source moment recovery and new finite-time adapter checks. No new source quadrature/projection or old transport solve is needed.

Time history is known on[0,T_end]. Evaluations outside that domain, including invented post-end zero, are refused. Fixed proper-volume density integrals are meaningful without a supplied numerical cell volume; worldtube counts require that volume. Incident surface flux requires extra geometry and is not a volume source in this implementation.

Actual nb is null. Consequently actual per-baryon/native25 is null. For genuine baryon injection the normalization changes and the exact quotient is mandatory.

Actual PHYS02→PR107 andPHYS02→PR108 links are gated by the physical-state mismatch. This is an input-compatibility decision, not a theorem excluding a future matched operator or explicit transport. RR moments from the old frozen10000K bath remain unchanged. Missing retained-photon output is null. No caloric partition or cutoff crossing is promoted to physical heating.
