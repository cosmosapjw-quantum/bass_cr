# C06 — 변경 구현과 실제 native 검증

57개 검증이 실제 통과했다. 스칼라 exact-rational resolvent, 유한시간 bound, 비대칭 2×2, zero-age/reward, negative/invalid input, positive-error underflow, 공통 N/E 에너지 상쇄, native25 별도 nb 제어와 중복 time-bin 거부를 확인했다. 두 실제 finest 연산자에서 양의 witness를 확인하고 네 작은 clock의 32 RHS 표본을 독립 C9에 결속했다. 실제 primary RHS는 아직 0이다.

첫 v1은 namespace PID와 procfs PID 불일치로 계산 출력 전에 중단됐다. 실제 비용 .002113 worker + .112583694 coordinator CPU초를 보존했다. 자식 proc/self 식별자와 시작시각을 현재 lease에 결속하는 수정은 독립 PASS를 받았다. v2 실제 PASS 비용 .332836 worker + .151952666 coordinator, 현재 합계 .59948536/60 CPU초다. 물리 입력·연산자·허용오차·예산은 유지했다. 일시적 실행환경 단절은 별도 기록했고 그동안 새 과학 실행은 없었다.

실제 native는 binary64, extended64 long double, round-to-nearest를 확인했다. C9 전체 독립 참조 판정은 후속 단계다.
