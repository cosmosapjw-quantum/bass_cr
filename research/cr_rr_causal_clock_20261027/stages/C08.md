# C08 — 저장 구간·격자·영역·재현성 및 그림

동결된 coarse/fine clock와 실제 여섯 discretization 결과를 구분해 검토했다. 최종 구간은 유효 level의 교집합과 단조성으로 좁혔으며 raw level을 보존했다. 양의 witness·산술 상계·격자·영역 endpoint 비교와 source/native/실행 snapshot의 전후 해시를 확인했다. 격자·영역 비교를 연속 물리 오차 상계로 승격하지 않았다.

PINNED RESULT.json만 읽는 plot worker로 PNG/PDF를 만들고 PNG를 직접 확인했다. proper seconds, source 대안, count/photon 정규화, interval band와 표시용 midpoint, zero-time의 log축 생략이 명확하다. 새 solver/provider/ODE 호출은0이다. 시각화 worker4.19512 + coordinator.179039386 CPU초, 종료된 primary lease 때문에 시작 전 거부된 plotv1 coordinator.086162841까지 포함해 누적18.043115737/60이다.

Primary의 끝난 lease 원문을 보존하고 동일 nonce·terminal receipt·없어진 실제 host PID·exec session exit0을 확인한 뒤 해당 lease만 정리했다. 공유 파일 lifecycle 원인은 미입증 상태로 기록했다. 새 소유자 lease를 지우는 일반 cleanup은 하지 않았다.
