# R09 — 정식 결과와 구현 연결

정식 결과는 비음수 RR 누적 반환을 두 Erlang clock으로 감싸는 exact-K 정리다. 구현 범위를 HeIII count/kinetic2RHS, 6case, 6positive proper-time horizon, finest2case의3clocklevels 및4comparisoncase의finestlevel로 고정했다. 관측은10³–10⁷s의 선언된 시각이며 source exposure가 아니다. 독립 Decimal70은 실제 finest2grid의4shift×m4×2RHS=32RHS로 모든 중간벡터·radius·24scalar를 대조한다. 원래 finitegrid/domain 기준과 arithmetic·clock폭 기준을 실행 전에 고정했다. 이론의 다른 RR 채널 일반식은 유효하지만 이번 새 실행은 HeIII 두열에 한정한다.
